# Validação — edição de contas bancárias

Em 14 de agosto de 2026, o fluxo foi testado no preview do MuFinance React em desktop. A conta principal foi aberta pelo card de Contas, o editor exibiu o saldo base de R$ 18.421,00 e o ajuste rápido recebeu R$ 500,00 no modo **Adicionar**. O resumo calculou R$ 18.921,00 antes do salvamento.

Após salvar, o sistema exibiu o feedback “Conta atualizada”, atualizou a conta selecionada para R$ 18.921,00, atualizou o patrimônio local para R$ 32,9K e refletiu o novo total de R$ 32.911,00 no KPI “Saldo total”.
